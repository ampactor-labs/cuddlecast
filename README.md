# CUDDLECAST

A zine about the bats of the Jordan River in Salt Lake City, and about the
boxes people hang for them. №01 is the Bat Week issue, October 2026.

This repository is the site the zine's back cover points at:
ampactor.dev/cuddlecast/01/ for №01, /02/ for the next, and so on. GitHub
Pages serves it from `main`, at the root.

The zine is made with [stoop](https://ampactor.dev/stoop/), a press in one
web page. After the bell rings on an issue, MAKE THE SITE on stoop's shelf
writes a zip; what is inside its `cuddlecast/` folder replaces what is here.
Each issue's page is the issue file itself, so whoever opens it can read it
and make the next issue in it.

The science behind it is [Roostcast](https://ampactor.dev/roostcast/), which
simulates the temperature inside a bat house through a real summer, and the
Cuddlecast pilot, which will put temperature loggers in 30 to 40 boxes on
the river.
